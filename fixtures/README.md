# Fixtures de Columnia

Todas las fixtures versionadas aquí son sintéticas y deterministas. Consulta la
[política completa](../docs/reference/fixtures-policy.md) y el
[manifest verificable](manifest.json) antes de agregar una entrada.

No copies datos reales, PII, credenciales, rutas privadas ni artefactos de
ejecución en esta carpeta. Los temporales de smokes y benchmarks pertenecen a
`.local/`, no al árbol versionado.
