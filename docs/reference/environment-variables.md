# Variables de entorno

Esta es la tabla única de las variables que lee Columnia, al compilar, al
ejecutar o en sus herramientas. Columnia instalada no necesita ninguna: todas
sirven para compilar una distribución, medir o probar. `tools/release.ps1`
aborta si encuentra alguna de las de pruebas definida en la sesión, para que no
influya en un release.

`node tools/check-documentation.mjs` comprueba que cada variable `COLUMNIA_*`
que aparece en el código esté en esta tabla.

| Variable | Cuándo se lee | Para qué sirve |
| --- | --- | --- |
| `COLUMNIA_UPDATER_ENDPOINT` | Al compilar (`option_env!` en `src-tauri/src/updater.rs`) | URL HTTPS del manifiesto de actualizaciones. Si no se define, el updater queda apagado en esa compilación y Columnia no hace ninguna petición de red para actualizarse. Ver [Red, privacidad y telemetría](network-privacy.md). |
| `COLUMNIA_UPDATER_ASSET_BASE_URL` | `tools/release.ps1 -WithUpdater` | URL HTTPS base desde la que se descargarán los instaladores; con ella se escriben las URL del manifiesto. Ver [Publicar un release](../how-to/publish-release.md). |
| `COLUMNIA_UPDATER_CONTRACT_TEST` | `tools/check-updater-manifest.mjs` | Con `1`, acepta una clave pública de prueba; solo la usa `tools/test-updater-manifest.mjs`. |
| `COLUMNIA_TEST_HARNESS_MANIFEST` | Al compilar los tests de Rust (`src-tauri/build.rs`) | Con `1`, incrusta el manifiesto de Windows que necesitan los binarios de test para arrancar. Necesaria para `cargo test` en Windows. |
| `COLUMNIA_TEST_LOCALE` | `src/test/setup.ts` | Locale con el que corre Vitest (p. ej. `es-ES`); `npm run test:locale` la usa para repetir la suite con otra configuración regional. |
| `COLUMNIA_PROBE_PROFILE_FILE`, `COLUMNIA_PROBE_PROFILE_PARTS` | `src-tauri/src/dataset/perf_probe_tests.rs` | Archivo que perfila la sonda de REN-01 (`perf_probe_profile`) o al que aplica la propuesta la de REN-14 (`perf_probe_apply_proposal`) y, con cualquier valor, el tiempo de cada columna y de los duplicados. |
| `COLUMNIA_PROBE_COMPARE_ROWS`, `COLUMNIA_PROBE_COMPARE_SHUFFLED` | `src-tauri/src/dataset/perf_probe_tests.rs` | Filas de los dos Parquet que genera la sonda de REN-08 (`perf_probe_keyed_comparison`, 2 000 000 por defecto) y, con cualquier valor, el archivo comparado con las filas en otro orden. |
| `COLUMNIA_PROBE_GENERATE_CSV`, `COLUMNIA_PROBE_GENERATE_ROWS` | `src-tauri/src/dataset/perf_probe_tests.rs` | CSV que escribe la sonda de REN-13 (`perf_probe_generate_csv`) y sus filas (por defecto 100 000 000), para medir el disco temporal del perfil. |
| `COLUMNIA_PROBE_CAST_COLUMNS` | `src-tauri/src/dataset/perf_probe_tests.rs` | Columnas, separadas por comas, que la sonda de REN-14 (`perf_probe_apply_proposal`) pide convertir a número; por defecto todas. |
| `COLUMNIA_PROBE_FLOW_DIR`, `COLUMNIA_PROBE_FLOW_SKIP` | `src-tauri/src/dataset/perf_probe_tests.rs` | Carpeta cuyos datasets recorre la sonda del flujo completo (`perf_probe_full_flow`: cargar, perfil, Explorar, propuesta, perfil y Explorar otra vez) y archivos que omite, separados por comas. |
| `COLUMNIA_PROBE_ROWS` | `src-tauri/src/dataset/perf_probe_tests.rs`, `src-tauri/src/dataset/sqlserver_export_tests.rs` | Filas de la sonda de rendimiento (por defecto 300 000), de la de las filas comparadas de una página de conflictos (AUD-038, `perf_probe_compared_rows_of_a_conflict_page`, 3 000 000) y de la del paquete BULK INSERT (AUD-041, `bulk_package_timing_probe`, 2 000 000). |
| `COLUMNIA_PROBE_TEXT_COLUMNS` | `src-tauri/src/dataset/perf_probe_tests.rs` | Columnas de texto del Parquet de la sonda de AUD-038 (`perf_probe_compared_rows_of_a_conflict_page`, por defecto 40). |
| `COLUMNIA_PROBE_RELOAD_FILE`, `COLUMNIA_PROBE_RELOADS`, `COLUMNIA_PROBE_RELOAD_STEPS`, `COLUMNIA_PROBE_RELOAD_PAUSE_MS` | `src-tauri/src/dataset/perf_probe_tests.rs` | CSV, número de recargas (por defecto 20), pasos que se repiten (`load,profile,history`) y pausa en milisegundos antes de medir, en la sonda de memoria de REN-02 (`perf_probe_reload_memory`). |
| `COLUMNIA_PROBE_ODBC` | `tools/probe-webview2-native-selectors.mjs` | Cadena de conexión de SQL Server para que la sonda de la app real pruebe también la entrega remota. |
| `COLUMNIA_PROBE_SCREENSHOT_DIR` | `tools/probe-webview2-native-selectors.mjs` | Carpeta opcional donde la sonda guarda una captura por fase. |
| `COLUMNIA_ODBC_SQLSERVER`, `COLUMNIA_ODBC_POSTGRESQL`, `COLUMNIA_ODBC_MYSQL` | Tests ignorados de `src-tauri/src/remote_databases.rs` | Cadenas de conexión de sesión para las pruebas ODBC externas (`cargo test --lib -- --ignored external_`). Usa una base de pruebas propia. Con `COLUMNIA_ODBC_POSTGRESQL` y `COLUMNIA_ODBC_MYSQL` también corren `external_odbc_import_postgresql` y `external_odbc_import_mysql`, que crean su propia tabla `columnia_aud074_*` en esa base, la importan como texto (tope de filas, nulos, tildes) y la borran. |
| `COLUMNIA_ODBC_SQLSERVER` (y opcional `COLUMNIA_BULK_DIR`) | Pruebas ignoradas `external_sql_server_runs_*` de `src-tauri/src/dataset/sqlserver_export_tests.rs` (AUD-075) | Generan con la ruta real de exportación el script T-SQL y el paquete BULK INSERT (crear, volver a crear, añadir y actualizar por clave) sobre una tabla `columnia_aud075_*` con nombres y valores hostiles (`]`, `'`, `"`, saltos de línea, emoji, texto largo, vacíos y nulos), los ejecutan por ODBC y comparan filas y conteos con el DataFrame; borran la tabla al final. Usa una base de pruebas propia (`cargo test --lib external_sql_server_runs -- --ignored`). `BULK INSERT` lee el CSV desde el disco del servidor con el permiso del inicio de sesión (con autenticación de Windows, el de quien ejecuta); si el servicio no lee la carpeta temporal, `COLUMNIA_BULK_DIR` indica otra carpeta legible. |
| `COLUMNIA_ODBC_IMPORT`, `COLUMNIA_ODBC_IMPORT_TABLE` | Test ignorado `external_odbc_import_reads_a_table_as_text` de `src-tauri/src/remote_databases.rs` | Cadena de conexión de SQL Server y tabla `esquema.tabla` que la importación lee (25 filas). Solo lee: no escribe en el servidor; la garantía real es que el usuario de la cadena solo tenga permiso de lectura. |
| `COLUMNIA_ODBC_IMPORT_ROWS` | Test ignorado `external_odbc_import_reads_a_table_as_text` | Opcional: límite de filas de la importación (25 por defecto). Por encima de 25, la prueba solo lee el pie del Parquet (filas y grupos) y no carga la tabla, para medir la memoria de la importación. |
| `COLUMNIA_ODBC_IMPORT_SURROGATE_TABLE` | Test ignorado `external_odbc_import_survives_lone_surrogates` | Con `COLUMNIA_ODBC_IMPORT`: tabla `esquema.tabla` con una celda de texto con un sustituto UTF-16 suelto (en SQL Server, `NCHAR(0xD800) + N'x'`). Comprueba que la importación no entra en pánico y que la columna aparece en `replaced_columns`. Se omite si la variable no está definida. Solo lee. |
| `COLUMNIA_ODBC_EXPECT_TABLES`, `COLUMNIA_ODBC_EXPECT_ROWS` | Test ignorado `external_odbc_catalog_lists_wide_names` | Con `COLUMNIA_ODBC_IMPORT`: tablas `esquema.tabla` separadas por `;` que deben aparecer con su nombre exacto (por ejemplo, con `ñ` o tildes) y, opcional, el número de filas que debe dar la primera al importarla. Solo lee. |
| `COLUMNIA_TSQL_OUT` | Test ignorado `writes_sqlserver_samples_for_a_real_server` de `src-tauri/src/dataset/sqlserver_export_tests.rs` | Carpeta donde escribe un script T-SQL y un paquete BULK INSERT de muestra para ejecutarlos a mano contra un SQL Server de pruebas. |
| `COLUMNIA_DUCKDB_JOIN_TARGET_MIB` | Test de JOIN grande y `tools/benchmark-duckdb-join.ps1` | Tamaño en MiB del CSV generado para medir el JOIN de DuckDB. |
| `COLUMNIA_BENCHMARK_CANCELLATION_INPUT`, `COLUMNIA_BENCHMARK_CANCELLATION_OUTPUT` | Test de cancelación y `tools/benchmark-datasets.ps1` | Archivo de entrada y carpeta de salida de la medición de cancelación. |
| `COLUMNIA_CANCELLATION_BENCHMARK_JSON` | Salida, no entrada | Prefijo de la línea con la que el test de cancelación entrega su resultado a `tools/benchmark-datasets.ps1`. |
| `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` | WebView2, durante `tools/capture-release-evidence.ps1` | La herramienta la define temporalmente con `--remote-debugging-port` para capturar la evidencia visual y restaura el valor anterior al terminar. |
