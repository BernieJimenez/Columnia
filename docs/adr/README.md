# ADRs de Columnia

Los ADRs (Architecture Decision Records) registran decisiones duraderas, su
motivo y sus consecuencias. No sustituyen las pruebas ni el código actual.

| ADR | Estado | Tema |
| --- | --- | --- |
| [0001](0001-contratos-del-repositorio.md) | Reemplazada en parte por 0002 | Licencia, Windows x64 inicial, frontera Rust/UI, validación local y fixtures |
| [0002](0002-motores-entrega-y-distribucion.md) | Aceptada | Polars y DuckDB, entrega ODBC, updater, persistencia SQLite, informes de fallo locales, distribución solo como código fuente y uso personal |

Antes de agregar un motor de datos, servidor, telemetría, capability Tauri,
política de release o cambio de licencia, añade un ADR y enlázalo desde este
índice.
